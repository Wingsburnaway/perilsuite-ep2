# Peril Suite · EP 2

Project site for the Peril Suite EP 2 record tracker.

Live (GitHub Pages): https://wingsburnaway.github.io/perilsuite-ep2/

This repository contains only the public site files. The site is open — anyone with the URL can view it. There is no login. Lyrics and stage status are published in `data.js` and update when the site is re-uploaded.

Do not commit a `private/` folder, plaintext passwords, rate figures, preview screenshots, or the 7 MB master banner PNG. The site serves web-optimized brand files under `assets/brand/`.
